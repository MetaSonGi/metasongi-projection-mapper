# MetaSonGi Projection Mapper


안드로이드부터 개발하는 휴대폰 기반 프로젝션 매핑 앱입니다.


## 현재 상태

안드로이드 이미지 매핑 소스와 프로젝트 생성 도구를 추가했습니다. 이미지 1장·사각형 1영역, 꼭짓점 편집·원근 변환·외부 디스플레이 출력·저장/불러오기를 구현했습니다. 동영상·여러 영역은 후속 범위입니다. Android SDK가 없어 APK 빌드·기기 검증은 아직 하지 못했습니다.

## 빠른 실행

```bash
python setup_android.py
```

자세한 실행 순서와 구현 제한: [RUN.md](RUN.md) · 검증 결과: [VALIDATION.md](VALIDATION.md)

## 전체 개발 로드맵 (아래 항목은 최종 목표)
- [ ] 외부 디스플레이 연결 감지와 프로젝터 전용 출력
- [ ] 휴대폰 편집 화면과 외부 출력 화면 분리
- [ ] 사각형 영역 추가와 네 꼭짓점 조절
- [ ] 사진·동영상 배치, 영역 마스킹과 반복 재생
- [ ] 프로젝트 저장·불러오기


## 개발 순서
1단계: 기기 HDMI 출력 검증 → 2단계: 테스트 패턴과 사각형 워핑 → 3단계: 미디어·마스크 → 4단계: 저장과 기기 테스트.


## 설계와 프로젝트 경계
Android 네이티브 앱을 우선합니다. 현재 첫 버전은 Java + Android Canvas/Matrix + Presentation입니다. Kotlin·GPU 렌더링은 후속 검토 항목입니다. SIFT 직접 매칭과 AR Foundation 런타임 이미지 등록은 별도 기술 검토 항목이며, AR 추적만으로 프로젝터 좌표 보정이 완료되지는 않습니다. iOS는 후속 단계입니다.
